Fluxos recomendados

Principal: obra nova completa

Use quando uma nova obra entra no Drive e precisa seguir todo o processo até o Notion.

1. Auditar 2. Organizar 3. Catalogar 4. Localizar ID 5. Gerar CSV 6. Sincronizar 7. Metadados
Alternativo 1: capítulos novos

Use quando a obra já existe e apenas recebeu novos capítulos no Drive.

3. Catalogar 6.4 Atualizar existentes
Alternativo 2: atualizar metadados

Use quando os IDs já estão confirmados e você deseja atualizar os dados externos, exportá-los para o CSV e atualizar as páginas existentes.

5.2 Consultar API 5.1 Atualizar CSV 7. Atualizar Notion
Origem: integrations/buscaIds.json
Cache: data/mangaupdates.json
Destino: integrations/manhwateca_import.csv
Alternativo 3: revisar IDs duvidosos

Use quando a busca marcar obras com Status: Revisar. O relatório permite comparar título, tipo, ano, pontuação, sinopse e a ficha externa.

3. Catalogar 4.1 Buscar IDs 4.2 Atualizar candidatos 4.3 Gerar página de revisão Selecionar candidatos Exportar decisões em JSON 4.4 Importar decisões 5.2 Consultar API 5.1 Atualizar CSV 7. Atualizar Notion
Origem: integrations/buscaIds.json
Relatório: audits/mangaupdates_id_review.html
Decisões: mangaupdates_id_decisions.json
Alternativo 4: importar obras já catalogadas

Use quando o catálogo local já está atualizado e não é necessário consultar novamente o MangaUpdates.

6.1 Simular lote 6.2 Importar lote
Alternativo 5: corrigir organização ou nomes

Use quando relatórios ou revisão manual apontarem pastas, capítulos ou capas fora do padrão.

1.1 Verificar 1.2 Padronizar arquivos 2.1 Organizar pastas 3. Recatalogar
Alternativo 6: auditar sem alterar nada

Use para conferir a biblioteca e as integrações sem aplicar mudanças nos arquivos ou no Notion.

1.1 Gerar relatórios 9. Executar testes 6.1 Simular lote
