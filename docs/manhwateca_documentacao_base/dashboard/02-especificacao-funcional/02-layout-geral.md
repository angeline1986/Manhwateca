# 02. Layout Geral

O sistema utiliza um layout de "Painel Administrativo Moderno" com foco em legibilidade e espaçamento.

### Estrutura de Grid:
- **Sidebar (Navegação):** Fixa à esquerda com 260px de largura.
- **Workspace (Conteúdo):** Área fluida à direita, com preenchimento interno (`padding`) variável via `clamp` para responsividade.
- **Dashboard Grid:** Utiliza um layout de duas colunas (proporção aproximada 2/3 e 1/3) para organizar pendências e integrações.

### Cores e Estilo (Design System):
- **Paleta:** Tons de Rose (`#a94d6b`) e Soft Pink (`#fbfafb`).
- **Cards:** Bordas arredondadas (22px a 28px) com sombras suaves para indicar profundidade.
- **Tipografia:** Inter ou Plus Jakarta Sans (foco em fontes geométricas).
