# 05. Métricas (Summary Cards)

Uma linha de 4 cards informativos sobre o volume de dados.

### Campos:
1.  **Total de Obras:** Soma de todos os registros na tabela `obras`.
2.  **Novos Capítulos:** Contagem de arquivos detectados na pasta local que ainda não foram marcados como "lidos" ou "sincronizados".
3.  **Sem ID:** Contagem de obras onde `manga_updates_id` é nulo.
4.  **Notion:** Contagem de registros onde a data de modificação local é superior à data de última sincronização com o Notion.
