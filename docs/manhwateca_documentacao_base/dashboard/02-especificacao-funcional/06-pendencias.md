# 06. Pendências Acionáveis

Lista de itens que exigem decisão manual do usuário.

### Estrutura de cada item:
- **Ícone Representativo:** (Ex: "ID" para identificação, "N" para Notion).
- **Título e Descrição:** Explicação clara do problema.
- **Status Pill (Badge):**
    - `Ação necessária` (Vermelho): Bloqueia o progresso do workflow.
    - `Revisar` (Laranja): Sugestão de melhoria ou verificação.
    - `Pendente` (Cinza): Aguardando execução.
    - `OK` (Verde): Item concluído.
