# Especificação Funcional - Dashboard

Este diretório contém a documentação detalhada para a implementação da tela principal do sistema Manhwateca.

## Objetivo
O Dashboard serve como o centro de controle e diagnóstico da aplicação, consolidando informações de diversas fontes (Banco de Dados Local, Google Drive, MangaUpdates e Notion).

## Organização da Documentação
A documentação foi dividida em módulos para facilitar a consulta técnica e o desenvolvimento isolado de componentes.
