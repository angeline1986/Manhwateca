# 03. Cabeçalho (Topbar)

O cabeçalho é fixo no topo da área de trabalho e utiliza um efeito de desfoque (`backdrop-filter: blur`) sobre o fundo.

### Elementos:
1.  **Eyebrow:** Texto "MANHWATECA WORKSPACE" em caixa alta, espaçamento entre letras aumentado.
2.  **Título H1:** Nome da página atual ("Dashboard").
3.  **Subtítulo:** Frase explicativa curta sobre a função da tela.
4.  **Botão de Ação Primário:** Rótulo "Recarregar dados". 
    - **Função:** Dispara uma nova varredura rápida nos serviços para atualizar os números exibidos.
