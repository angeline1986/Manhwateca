# 11. Navegação (Sidebar)

A Sidebar controla o roteamento da aplicação.

### Estados:
- **Active:** O botão correspondente à página atual deve ter fundo branco, sombra e cor do texto em destaque (Rose).
- **Hover:** Mudança sutil de cor de fundo para indicar interatividade.
- **Responsividade:** Em telas menores, a sidebar se transforma em um menu horizontal no topo com scroll lateral.
