# Bem-vindo ao Manual do Usuário

Este manual foi criado para ajudar você a utilizar o **Dashboard** da Manhwateca de forma eficiente.

O Dashboard é a principal tela da aplicação e funciona como um **centro de comando**, reunindo em um único lugar as informações mais importantes sobre sua biblioteca, o progresso do Workflow, a saúde das integrações e as ações que exigem sua atenção.

Este manual foi organizado para que você possa aprender desde os conceitos básicos até a utilização de cada componente da interface.

---

# Para quem é este manual?

Este material é destinado a qualquer usuário da Manhwateca, independentemente do nível de experiência.

Ele foi escrito especialmente para quem deseja:

* entender como o Dashboard funciona;
* interpretar corretamente as informações exibidas;
* saber quando uma ação é necessária;
* utilizar a aplicação de forma mais produtiva;
* resolver dúvidas comuns sem consultar documentação técnica.

Não é necessário possuir conhecimentos sobre banco de dados, APIs ou programação.

---

# O que você encontrará neste manual?

Ao longo deste guia, você aprenderá:

* qual é a função do Dashboard;
* como interpretar cada informação apresentada;
* como acompanhar o progresso da organização da biblioteca;
* como identificar problemas de integração;
* como utilizar os atalhos disponíveis;
* quando atualizar os dados do Dashboard;

# Conhecendo o Dashboard

O Dashboard reúne informações provenientes de diferentes partes da aplicação.

Em vez de navegar por vários módulos para descobrir o estado da biblioteca, basta acessar esta tela para visualizar um resumo completo da situação atual.

Entre as principais informações apresentadas estão:

* quantidade de obras cadastradas;
* novas atualizações encontradas;
* pendências que exigem atenção;
* progresso do Workflow;
* estado das integrações;
* ação recomendada para continuar o processo.

---

# Como navegar pelo Dashboard

A utilização do Dashboard segue um fluxo simples:

1. Acesse o Dashboard.
2. Verifique a **Ação Recomendada**.
3. Analise as métricas da biblioteca.
4. Consulte as pendências existentes.
5. Verifique se todas as integrações estão operacionais.
6. Acompanhe o progresso do Workflow.
7. Utilize as **Ações Rápidas** para acessar outros módulos quando necessário.

Na maioria das situações, esse fluxo é suficiente para manter a biblioteca organizada e atualizada.

---

# Dicas de utilização

> Consulte o Dashboard sempre que iniciar uma nova sessão na Manhwateca. Ele foi projetado para mostrar rapidamente o estado geral da sua biblioteca.

> Priorize sempre a **Ação Recomendada**. Ela indica a atividade mais importante naquele momento.

> Antes de iniciar um novo processo, verifique o painel de **Integrações**. Problemas de configuração podem impedir a execução correta do Workflow.

> Utilize o botão **Recarregar** sempre que concluir uma etapa importante ou retornar de outro módulo da aplicação.

# Estrutura do Dashboard

O Dashboard é composto pelos seguintes componentes principais.

```text
Dashboard
│
├── Cabeçalho
├── Ação Recomendada
```
