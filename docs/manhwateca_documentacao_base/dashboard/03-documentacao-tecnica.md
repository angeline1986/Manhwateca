## ADRs


| ID         | Título                                  | Objetivo                                                                                                                |
| ---------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **US-001** | Visualizar o estado geral da biblioteca | Permitir que o usuário veja rapidamente a situação geral da biblioteca, integrações e workflow.                         |
| **US-002** | Receber a próxima ação recomendada      | Indicar automaticamente qual deve ser o próximo passo do workflow com base nas pendências existentes.                   |
| **US-003** | Visualizar métricas operacionais        | Exibir indicadores consolidados, como quantidade de obras, novos capítulos, obras sem ID e páginas pendentes no Notion. |
| **US-004** | Consultar pendências críticas           | Apresentar somente pendências que exigem intervenção do usuário e que impactam o fluxo de trabalho.                     |
| **US-005** | Acessar ações rápidas                   | Disponibilizar atalhos para as principais operações sem navegar por diversos módulos.                                   |
| **US-006** | Acompanhar o progresso do workflow      | Mostrar em qual etapa do processo a biblioteca se encontra e quais etapas já foram concluídas.                          |
| **US-007** | Consultar o estado das integrações      | Informar a saúde das integrações (PostgreSQL, Biblioteca, MangaUpdates e Notion).                                       |
| **US-008** | Atualizar os dados do Dashboard         | Permitir recarregar todas as informações exibidas na tela sem reiniciar a aplicação.                                    |
| **US-009** | Navegar para os módulos especializados  | Direcionar o usuário para Biblioteca, Fluxos ou Configurações quando uma ação exigir maior interação.                   |
